# 02. Эмулятор C166

[`tools/c166emu.py`](../../tools/c166emu.py) исполняет код образа MS42 или MS43 команду за командой на декодере [`c166.py`](01-c166-tools.md). Python 3, других пакетов не нужно.

## Что эмулируется

- Каждая команда C167 с действием и флагами E, Z, V, C, N из руководства Infineon *Instruction Set Manual for the C166 Family* V2.0. В том числе: `ADDC` и `SUBC` оставляют Z, только если он был установлен до них; V у `SHR`, `ASHR` и `ROR` — флаг округления по выдвинутым битам; `MUL`, `DIV` и родственные ставят V и MDC.MDRIU; `PRIOR`; флаги битовых команд по прежним состояниям битов; `BFLDL` / `BFLDH` подмешивают данные через OR как есть; `JBC` и `JNBS` меняют проверяемый бит.
- Регистры общего назначения лежат во внутренней RAM по CP, поэтому `SCXT CP` переключает банк. Системный стек идёт по SP; `CALLS` и `RETS` кладут и снимают CSP; `TRAP` и `RETI` учитывают SYSCON.SGTDIS.
- Регистры, на которые опирается код: DPP0-DPP3 (записанное значение действует), CSP (только чтение), CP, SP, PSW, MDH, MDL, MDC, ZEROS, ONES, SYSCON. `EXTP`, `EXTS`, `EXTPR` и `EXTSR` с константой или регистром, `EXTR` для расширенных SFR.
- Память: флеш берётся из образа через профиль `c166.py` и никогда не пишется. Системная страница 0xC000-0xFFFF (XRAM, CAN, ESFR, IRAM, SFR) и окна RAM профиля (внешняя RAM MS43) начинаются с нулей.
- Не эмулируются: прерывания, периферия (регистр периферии возвращает то, что в него записали), время, сторожевой таймер.

Эмулятор останавливается исключением `Stop` и называет причину: байты, которые не команда, слово по нечётному адресу, запись во флеш, чтение вне карты памяти, `SRST`, `IDLE` или `PWRDN`, предел шагов.

## Как пользоваться

| Команда | Что делает |
|---|---|
| `python3 tools/c166emu.py call ОБРАЗ АДРЕС [r12=0xF758] [0xF756=0x3643] [--near] [--steps N] [--trace]` | Запускает функцию по смещению в файле (по умолчанию дальнюю, `--near` для вызываемой `CALLA` / `CALLR`) с заданными регистрами и словами памяти; печатает регистры, с `--trace` — последние команды |
| `python3 tools/c166emu.py crc ОБРАЗ` | Обе контрольные суммы программы, посчитанные её же подпрограммой CRC, рядом с записанными |

Как библиотека:

```python
from c166emu import Emu
emu = Emu(img)                 # профиль по метке программы
emu.r[12] = 0xF760             # регистры общего назначения
emu.wr16(0xF756, 0x3643)       # память по физическому адресу
emu.call(0x75D8E)              # дальняя функция; near=True для CALLA / CALLR
emu.hooks[0x1234A] = f         # f(emu) перед командой по смещению в файле; True — пропустить её
```

## Как проверено

`python3 tests/test_c166emu.py`; GitHub Actions запускает его в каждом pull request вместе с заводскими образами.

- Каждая группа команд против действия и флагов из руководства, 16 кодов условий из его таблицы 5, адресация через DPP, EXTP, EXTS и EXTR, стек, `TRAP` и `RETI`.
- **Собственная подпрограмма CRC программ.** Обе программы проверяют флеш в фоновой задаче: подпрограмме CRC-16 (0110C6: `calls 07:5D8E`, 430069: `calls 0E:3642`; r12 указывает на дальний указатель, r13 на CRC, в r14 число байт) скармливаются блоки двух описателей (сумма, число блоков, блоки): MS42 0x4FEE0 (калибровка) и 0x50306 (программа), MS43 0x73FE0 и 0x6FDE0. Каждый CRC задача начинает с двух байт ASCII из строки опознания: MS42 читает их в 0x4800C и 0x50032 (`C6` из `0110C6` даёт 0x3643, `00` даёт 0x3030), MS43 — через дальние указатели в 0x6ED5A и 0x6ED42. Исполненная эмулятором на 34 заводских образах ms4x-net, подпрограмма даёт то же, что независимый CRC-16 (полином 0xA001, отражённый), — больше четырёх миллионов команд скомпилированного кода на один программный CRC MS43 — и суммы, записанные в образах.
- Один заводской образ не сходится сам с собой: в `Siemens_MS43_MS430069_E39_M54B25_EU4_LHD.bin` из ms4x-net записана калибровочная сумма 0x5ADF, а содержимое даёт 0xC138, и подпрограммой программы, и независимым CRC.
- Каждая функция, достижимая в коде (документ 01), запущенная с нулевой RAM, возвращается или останавливается на том, о чём эмулятор сообщает, но никогда на ошибке самого эмулятора. С нулевой RAM возвращаются 415 из 471 функции MS42 и 497 из 650 функций MS43; остальные ждут железо или идут по указателю, который ещё нулевой.
- Скорость: около 400 000 команд в секунду.

## Ограничения

- Нет прерываний и периферии: код, который ждёт таймер, АЦП или флаг CAN, идёт до предела шагов; задайте регистр, которого он ждёт, или замените вызов крючком.
- Значения DPP начинаются со значений запуска из профиля; код, который грузит другие, отслеживается, а код, который полагается на значения, заданные где-то ещё, требует задать их заранее.
